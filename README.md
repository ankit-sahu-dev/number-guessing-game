# 🎮 Number Guessing Game

A beginner-friendly Number Guessing Game built using Python.

## 🚀 Features
- Generates a random number between 1 and 100.
- Takes guesses from the user.
- Gives hints: Too high or Too low.
- Counts the total attempts.
- Congratulates the player when they win.

## 🛠️ Technologies Used
- Python
- Random Module
- While Loop
- If-Else Statements

## ▶️ How to Run

```bash
python number_guessing_game.py
```
